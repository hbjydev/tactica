# AGENTS.md

Laravel 13 + Inertia.js v3 + React 19 (TSX). PHP 8.4, Bun (not npm/yarn/pnpm),
PostgreSQL in dev, SQLite `:memory:` for tests. DDEV is the canonical dev
environment.

## Setup

```bash
composer run setup
# composer install → .env → key:generate → migrate → bun install → bun run build
```

## Dev server

The dev server is usually already running, and is reachable at
`https://tactica.ddev.site`. If it _isn't_, you can start it using:

```bash
# starts the server in the background
ddev start

# runs the vite dev server in the foreground
ddev vite
```

## Commands

| Task | Command |
|------|---------|
| Build (frontend) | `bun run build` / `bun run build:ssr` |
| PHP lint (fix) | `composer run lint` |
| PHP lint (check) | `composer run lint:check` |
| JS lint (fix) | `bun run lint` |
| JS lint (check) | `bun run lint:check` |
| JS format (fix) | `bun run format` |
| JS format (check) | `bun run format:check` |
| Typecheck | `bun run types:check` |
| All CI checks | `composer run ci:check` |
| Tests | `php artisan test` |
| Single test | `php artisan test --filter "Name"` or `tests/Feature/Foo.php` |
| Migrations | `php artisan migrate` |

`composer run test` also runs `lint:check` — use `php artisan test` directly for tests only.

## Generated / vendored — never edit

- `resources/js/wayfinder/` — generated by Laravel Wayfinder at build/dev time (typed route helpers)
- `resources/js/components/ui/` — shadcn/ui components, treated as vendored; excluded from lint and format

## Toolchain quirks

- **Bun** is the JS package manager. `bun.lock` is the lockfile. Ignore `pnpm-workspace.yaml` — it's a leftover.
- **oxfmt** enforces: single quotes, 4-space indent, 80-char width, auto-sorts Tailwind classes in `clsx`/`cn`/`cva` calls.
- **React 19 compiler** (`babel-plugin-react-compiler`) is active via Vite config.
- `@/*` TS alias → `resources/js/*`; `@legal/*` → `docs/hosted/legal/`
- Vite dev server hardcoded to port 5173; origin is set from `DDEV_PROJECT` env var.

## Testing

- Pest 4; all Feature tests get `RefreshDatabase` automatically (set in `tests/Pest.php`)
- Test DB is SQLite `:memory:` via `phpunit.xml` — no external DB needed
- Cache, session, broadcast, queue are all nulled in test env
- No JS test suite

## Architecture notes

- Multi-tenant: wildcard subdomain routing (`*.tactica` locally). `APP_DOMAIN` drives session domain, URL, and mail — don't hardcode URLs.
- `SESSION_ENCRYPT=true` — rotating `APP_KEY` invalidates all sessions.
- OpenTelemetry autoloaded via `OTEL_PHP_AUTOLOAD_ENABLED=true`; ships to `otel-collector` sidecar in prod.

## CI

Workflows trigger on push/PR to `develop`, `main`, `master`, `workos`:
- `lint.yml`: `ddev bun run format:check` → `lint:check` → `ddev composer run lint:check`
- `tests.yml`: `ddev php artisan test`

CI uses DDEV. Locally you can run commands without `ddev` if you have PHP/Bun installed directly.
